How Server B Was Created

Server B (Nuhapumppu) was created from a snapshot of Server A (Tinpan_Linux) in CSC cPouta. A new floating IP address was assigned to Server B.

Backups

The /var/www/html directory is backed up hourly from Server A to Server B using rsync, SSH keys and cron. Backups are stored outside the public web directory under /srv/backups/www.

Database Replication

MariaDB replication continuously copies changes from Server A to Server B. The visitor counter shown on this page comes from Server B's local replicated database.

Users and Permissions

The Linux user ubuntu is used for application files. Backup files are owned by root and stored with restricted permissions. A dedicated MariaDB user named replicator is used for database replication.

Tests Performed

  • Both pages are publicly accessible.
  • Loading Server A increases the counter.
  • The updated value appears automatically on Server B.
  • Loading Server B does not increase the counter.
  • Two backup versions were created successfully.
  • A test file was restored successfully.
  • MariaDB replication status reports healthy operation.

What I Learned

I learned how to create a server snapshot, configure SSH-based backups with rsync, and build MariaDB replication between two Linux servers.
