Week 4 Documentation

Server A: http://195.148.22.121/viikko2/

Server B: http://128.214.252.183/viikko4/

Server B was created from a cPouta snapshot of Server A.

Hourly backups are transferred from Server A to Server B using rsync and cron. The backup files are stored outside the web root and protected with root ownership.

MariaDB replication copies changes continuously from Server A to Server B. The replica page uses the local replicated database and does not modify it.
